    Method

    • Cost comes from the billing export in __BILLING_PROJECT__. "Net" is cost after credits. "Last 12 mo" covers __12M__ (complete months).
    • Last hands-on use is the newest Cloud Audit Log entry by a person (service accounts excluded). Changes come from Admin Activity logs, searched back to __SINCE_FULL__. Reads come from Data Access logs, which are kept only 30 days by default, so read-only use older than that is not visible. Browsing calls that fire for every project when someone opens the console or billing pages (project, billing-info, IAM-policy and org-policy lookups, log reads) are ignored, as is this audit's own activity. Last change counts only Admin Activity writes. Data Access logs also only exist for services where they are enabled.
    • IAM owners are members holding roles/owner directly on the project. Access inherited from folders or the organization is not listed.
    • Projects our account cannot read returned "permission denied" for metadata and logs. Recent billing records show the project still exists; none for months usually means it was deleted.
    • Top service accounts come from the newest 5,000 audit log entries per project, so on busy projects they cover only the most recent days. They show which automation is still running.
