# FinOps_GCP
Track Cost on GCP

- `GCP_FinOps.ipynb` — monthly cost report from the BigQuery billing export
- `GCP_Orphaned_Projects_Audit.ipynb` — audits the projects in `Google_Orphant_Accounts.txt` (cost, services, IAM owners, last use) and writes an HTML report + CSV using `templates/orphan_audit_template.html`
